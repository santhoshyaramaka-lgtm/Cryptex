## Bug Fix — Card Details Crash

- Opening a Card entry was crashing immediately after the card type label (FrameLayout) feature was introduced
- Root cause: `etEdit` was added to `cardFrame` (FrameLayout) and then unconditionally added to `row` again — a View cannot have two parents
- Fixed: added the same conditional guard that `tvView` already had before `row.addView(etEdit)`

---

## Root Cause Fix — Numeric Keyboard Override

`setRevealOpen()` was overriding all numeric keypad input types with `TYPE_CLASS_TEXT` every time edit mode was entered for secret fields. Fixed to check field type before applying input type.
