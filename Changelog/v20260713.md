# Changelog — v20260713

## Changes

### 1. Card Number Auto-Formatting (Card type)
- Card number field now auto-formats as `XXXX XXXX XXXX XXXX` while typing
- Spaces are stripped when copying to clipboard (clean digits only)
- View mode always displays card number with spaces, including old records saved without spaces
- Eye reveal in view mode now shows formatted number for old records
- Max length increased from 16 digits (19 chars) to 19 digits (23 chars) to support Maestro and UnionPay cards

### 2. Note Body Formatting Toolbar (Note type)
- Added a persistent formatting toolbar in edit mode with 4 options: `¶` (free text), `•` (bullet), `1.` (numbered), `H` (heading)
- Toolbar is hidden in view mode — only visible when editing
- Tapping a format button on an empty line inserts the prefix immediately (no need to press Enter first)
- Pressing Enter on a prefixed line auto-continues the format on the next line
- Pressing Enter on an empty prefixed line removes the prefix and reverts to `¶` (smart escape)
- Deleting the prefix manually via Backspace automatically reverts the toolbar to `¶`
- Heading (`H`) is one-shot per line — auto-reverts to `¶` after pressing Enter
- In view mode, `## Heading` lines render as bold, slightly larger text (prefix hidden)
- Old notes are unaffected — open as plain free text with `¶` active by default
